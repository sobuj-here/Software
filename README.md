## 🛠️ General Installation Instructions

1. **Download Archives:**
   - Click the download badge corresponding to your desired software suite to download the archive file from the MEGA cloud mirror.
2. **Extraction:**
   - Use [7-Zip](https://www.7-zip.org) or [WinRAR](https://www.win-rar.com) to extract multi-part or compressed `.rar` / `.zip` archives.
3. **Execution:**
   - Right-click the `Setup.exe` (or installer file) and select **"Run as administrator"**.
   - Follow the included on-screen instructions or read the accompanying `Readme.txt` within each package for post-installation configuration.
4. **Antivirus Consideration:**
   - Some license patches or emulators may trigger false-positive alerts by Windows Defender. Temporarily add the folder as an exclusion during setup if prompted.
